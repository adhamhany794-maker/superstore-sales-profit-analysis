# Superstore Sales & Profit Analysis

## Overview
A Python-based data analysis project using the Superstore dataset to analyze
sales, profit, products, regions, and customer behavior.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Objectives

- Analyze sales and profit performance.
- Identify trends across products, regions, and customers.
- Perform customer segmentation using RFM analysis.
- Create visualizations to support business insights.
  
## Workflow
Data Cleaning → Feature Engineering → EDA → Business Analysis → RFM Analysis → Visualization → Reporting

## Analysis

- Data Cleaning & Preparation
- Exploratory Data Analysis (EDA)
- Sales & Profit Analysis
- Product & Category Analysis
- Regional Analysis
- Customer Analysis
- RFM Customer Segmentation
- Data Visualization

## Outputs
- Cleaned dataset
- KPI summary
- Visual reports
